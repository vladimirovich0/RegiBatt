# Battery Passport Demo

Легковесная демонстрация полного процесса подготовки цифрового паспорта батареи для вымышленного импортёра **VoltRide Sp. z o.o.** Интерфейс полностью на русском языке.

## Место демо в плане проекта

Это локальный прототип активного этапа **Rovnota Data Readiness**, а не запущенный продукт. Он помогает проверить сценарий структурирования данных и поиска пропусков, но сам по себе не означает завершение этапа 1. Этап будет считаться выполненным только после развёртывания доступной пользователям рабочей версии и приёмочной проверки согласно [`PROJECT_PLAN.md`](../PROJECT_PLAN.md).

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Команда `npm install` автоматически создаёт реалистичные PDF, XLSX и CSV в `public/demo-documents`.

## Что показывает демо

Рабочий сценарий проходит этапы: документы поставщика → локальное извлечение и нормализация → поиск пропусков и конфликта → запрос и ответ поставщика → ручное подтверждение → версионированный JSON/CSV → 10 индивидуальных паспортов → симуляция EU Registry → уникальные QR-коды → публичные страницы паспортов.

Исходные значения не переходят напрямую в паспорт. В коде разделены `RawDocument`, `ExtractedCandidate`, `CanonicalBatteryField`, утверждённый набор, индивидуальный паспорт и запись регистрации. Состояние презентации сохраняется только в `localStorage`; кнопка «Сбросить демо» очищает его.

## Что реально работает

- включённые PDF/XLSX/CSV действительно создаются локально и доступны для скачивания;
- детерминированный Demo AI Engine возвращает значения, источники, фрагменты, страницы и уверенность;
- пропуски не выдумываются, конфликт 3.6/3.55 kg требует решения человеком;
- письмо можно скопировать или скачать, ответ поставщика — скачать и обработать;
- JSON и CSV формируются из утверждённой канонической модели;
- QR генерируются библиотекой `qrcode`, уникальны и ведут на рабочие маршруты `/passport/[serial]`;
- все QR можно скачать одним ZIP.

## Что симулируется

Отправка email, DPP-хостинг и EU Registry выполняются локальными реализациями. Идентификаторы `EU-DPP-DEMO-*` вымышлены. Приложение не создаёт юридически действительные паспорта и не заявляет соответствие полной официальной схеме ЕС. Пользовательские файлы можно добавить в интерфейс, но преднастроенный сценарий извлечения рассчитан на включённый комплект документов.

## Замена интеграций

В `src/lib/types.ts` определены интерфейсы `BatteryDataExtractor`, `SupplierCommunicationService`, `DppProvider` и `EuRegistryProvider`. Их демо-реализации находятся в `src/lib/services.ts`. Для подключения настоящего AI достаточно реализовать, например, `OpenAIBatteryDataExtractor` с тем же контрактом, сохраняя источники и кандидаты. Аналогично `LocalDppProvider` можно заменить на адаптер выбранной DPP-платформы, а `MockEuRegistryProvider` — на официальный API-клиент, когда такой API, полномочия и учётные данные доступны. UI и бизнес-последовательность менять не потребуется.
