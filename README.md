# Rovnota Systems

Rovnota Systems — компания, которая разрабатывает инструменты для автоматизации рабочих процессов. Основной домен — **rovnota.com**. Целевая структура сайта: главная о компании, отдельные страницы описания продуктов и их рабочие интерфейсы под общим аккаунтом.

Статический прототип публичной страницы и демонстрационного кабинета этапа 1 — Rovnota Data Readiness. Прототип показывает целевой пользовательский сценарий, но не является развёрнутым SaaS-продуктом.

Первый продукт помогает готовить данные для паспортов батарей. Будущие продукты могут отличаться названиями, функционалом рабочих пространств и акцентными цветами, сохраняя общую дизайн-систему. За батарейным продуктом закреплён зелёный. Конкретные новые направления пока не утверждены; многопродуктовая структура описывает развитие, а не уже реализованные возможности.

## Структура

- `index.html` — публичная страница.
- `workspace.html` — вход в демонстрационный кабинет.
- `documents.html`, `readiness.html`, `review.html`, `dataset.html` — шаги демонстрационного сценария.
- `assets/css/` — стили публичной страницы и кабинета.
- `assets/js/` — поведение публичной страницы и кабинета.
- `assets/images/` — графические ресурсы бренда.
- `AGENTS.md`, `PROJECT_PLAN.md`, `BRANDBOOK.md` — технические, продуктовые и визуальные правила проекта.
- `*.docx` — исходные исследовательские материалы.

## Локальный запуск

Сборка и установка пакетов не требуются. Откройте `index.html` напрямую либо запустите статический сервер из корня проекта:

```powershell
python -m http.server 8000
```

После этого сайт доступен по адресу `http://localhost:8000/`. Локальных программных зависимостей нет; шрифты прототип загружает из Google Fonts.

Целевая SaaS-архитектура и порядок будущей миграции описаны в `AGENTS.md`, границы этапов — в `PROJECT_PLAN.md`.
